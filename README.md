# core-spark



![preview](docs/preview.png)

CLI + library bits for local file chores.

_I needed this on a Sunday and did not want a 400-star framework._

## Features

- single purpose
- no telemetry
- works offline

## Usage

```bash
python -m pip install -r requirements.txt
python -m core_spark
```

## Notes

This is a starting point, not a platform.
